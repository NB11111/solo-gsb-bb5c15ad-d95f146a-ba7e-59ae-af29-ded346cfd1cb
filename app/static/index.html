事件快照 0

把当前事件关联结果保存为不可变快照：记录聚合间隔、每个事件的成员告警序号、确认状态与生成时间。 保存后撤销告警、调整聚合间隔或重算事件都不会改写历史快照（仅「恢复出厂」会随全部业务数据一并清空）。

快照对比（事件血缘）

任选两个快照，按成员交集建立确定性血缘：无交集的新/旧事件分别标记「新增 / 消失」；旧事件重叠多个新事件标记「拆分」， 新事件重叠多个旧事件标记「合并」（两者可同时出现）；其余有交集的标记「延续」；成员完全相同但确认状态变化的单独标记「确认变化」。 结果按新事件首时间、旧事件 ID 稳定排序，与对比发起时机无关。

新建抑制规则

匹配语义：设备 / 批次 / 级别为精确匹配（空或 * 通配）；时间段为每日循环窗口，支持跨午夜。所有启用规则按 (priority, id) 排序，首个匹配者决定动作；无匹配则默认放行。pass 规则在冷却窗口内对相同 设备|批次|级别|类型 指纹的后续告警执行抑制。
